# Recorded forward outcomes
The view in Recorded screens shows the six market/phase combinations from the immutable historical rule tracker: Home, Draw, Away for calibration (kickoffs before 1 December 2026) and post-boundary (on/after).
Unique market observations are selected through the existing `gerball_tracking_private.qualified_representatives` view, which deduplicates event aliases and repeated daily captures. Settlement uses the latest `result_revisions` record. The rate is matched/settled only; when zero settled, it is null, not 0%. Reviewed cases remain distinct from pending. Calendar boundaries are frozen on each original saved fixture's London kickoff date, not the import date or observation date.
The SQL function is read-only, SECURITY INVOKER, service-role-execute only. The Edge Function uses server-only credentials, GET only and the website's publishable application key. No private priced prediction ledger is revealed and no approval status is changed. This is *not* a betting ROI or evidence of executable profit.
The 25 November baseline contains saved future events with zero settled results. Result reconciliation runs hourly at :30 against previously imported football-data matches.
